1. 支持 Android/iOS 两个平台
   1. 核心音频代码跨平台复用
   2. 音频输出链路和上层的 ui 则是平台分开
2. 支持动态实时调节频率
3. 支持音量实时调剂
4. ui 界面设计

```text id="20x0ai"
┌──────────────────────────────────┐
│        ● RUNNING    🔒           │
│                                  │
│            00:32:18              │
│                                  │
│               180                │
│               BPM                │
│                                  │
├──────────────────────────────────┤
│      [-5]  [-1]  [+1]  [+5]      │
├──────────────────────────────────┤
│          START / PAUSE           │
├──────────────────────────────────┤
│     Tick Vol        Accent       │
│        80%            ON         │
└──────────────────────────────────┘
```

| 区域      | 内容                      | 推荐高度占比 | 备注         |
| ------- | ----------------------- | -----: | ---------- |
| 顶部状态区   | `RUNNING / PAUSED`、锁定状态 |  8~10% | 状态信息展示     |
| 运行时间区   | `00:32:18`              |  8~10% | 展示当前持续运行时间 |
| BPM 核心区 | `180 BPM`               | 45~50% | 页面主信息，超大字号 |
| BPM 调节区 | `[-5] [-1] [+1] [+5]`   | 12~15% | 快速调整 BPM   |
| 主控制区    | `START / PAUSE`         | 10~12% | 启停控制       |
| 底部状态区   | Tick Volume / Accent    |   6~8% | 展示当前参数状态   |
